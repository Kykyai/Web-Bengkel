# BengkelPro Backend API

REST API Server untuk Sistem Manajemen BengkelPro menggunakan **Node.js**, **Express.js**, dan **PostgreSQL / MySQL**.

## 🚀 Cara Menjalankan

1. Masuk ke folder backend:
   ```bash
   cd backend
   ```

2. Install dependensi:
   ```bash
   npm install
   ```

3. Jalankan server dalam mode development:
   ```bash
   npm run dev
   ```

4. Server akan berjalan di: `http://localhost:5000/api/health`
